# 术语与文案约定（v1.2.1）

> 目的：同一个概念只用一个词。代码标识符（`deck` / `session` / `capsule` / `hud.json` 等）沿用契约名，**不算文案混用**。
> 自动化：`npm run check` 会运行 `scripts/check-terms.mjs`，扫描 README / CHANGELOG / docs / 前端文案中的禁用词。

## 术语表

| 概念 | 采用 | 避免 | 说明 |
| --- | --- | --- | --- |
| 产品 / 界面 | **指挥台** | deck（中文叙述）、面板（指产品时） | 英文品牌句可保留 “command deck” |
| 桌面悬浮窗 | **桌面胶囊** / **胶囊** | 裸用 HUD、悬浮窗 | 技术桥接统一写「HUD 数据桥（`hud.json`）」；旧插件写「旧版 HUD」 |
| 对话 | **会话** | 对话（中文叙述）、session（中文句子） | `?s=` 参数与 `session` 字段属标识符，不算 |
| 活动流 | **实时流** | 活动流、日志流 | 卡片标题、文档、CHANGELOG 新段落统一 |
| 任务板 | **任务板** | 看板、Kanban | 指共享任务视图；整体界面用「指挥台」或「面板」 |
| 自检 | **自检** | 检查、体检 | 操作按钮：运行自检 / 重新自检 |
| 诊断 | **诊断** | 检测 | 报告称「诊断报告」；功能名「自检与诊断」 |
| 复制 | **复制** | 拷贝 | 提示统一「已复制」 |
| 编队 | **编队** / **成员** | 团队、队伍 | 指本次 agent 集合 |
| 审批 | **审批** / **待审批** | 确认（指审批动作时） | 「等待你确认」是胶囊状态文案，保留 |

## 文案规则

1. 按钮 = 动词短语（2–4 字）：运行自检、复制报告、开启远程访问、重新自检。
2. 成功提示 = 「已 + 动词」：已复制、已发送、已开启、已断开。
3. 失败提示必须给出下一步：请检查网络后重试 / 请检查胶囊进程后重试。
4. 提示停留分三档：ok 2.4 s、warn 3.6 s、error 4.8 s（`.toast[data-tone]`）。
5. 胶囊状态词固定：待命 / 进行中 / 等待你确认 / 已完成。
6. 中文与英文、数字与单位之间留一个半角空格（例：「8 项检查」「2.4 s」「Ctrl+K」）。
7. 中文句子用全角标点；按钮与短标签不加句号。

## 英文

- 品牌：**command deck**（对外标题）、**Cockpit**。
- 统一用词：capsule、session（对话语境可用 conversation）、live stream（不用 activity stream）、self-check、diagnostics report、copy。
- 对外文案避免裸用 “HUD”；技术桥接写 “HUD bridge (`hud.json`)”。

## 例外

- `docs/STATE.md` 是数据契约文档，正文可使用 `deck` / `session` / `capsule` / `hud.json` 等标识符；中文叙述仍按本表。
- `CHANGELOG.md` 的历史段落保留发布时原文（英文 release note 里的 deck / HUD 属于历史），新增段落按本表执行。
- 代码注释、变量名、文件路径不受本表约束。
