# Cockpit 路线图与优化清单

> 当前版本：**v1.0.0**（已发布：<https://github.com/zoe1nan/dsh-cockpit>）
> 本文档记录「已做到哪、还欠什么、下一步怎么排」，作为后续迭代的长期备忘。
> 更新规则：每完成一项，从对应清单移入「已完成」或在 CHANGELOG 留一行；新想法先加到 P2，不直接插队。

---

## 0. 一句话现状

Cockpit 已经把「看 / 批 / 说 / 盯」四件事做完了：看板看全局、审批一键过、发消息插话、桌面胶囊和手机远程盯着。**v1.0 是「能用且好用」，接下来是「稳、广、深」**。

| 维度 | 现在 | 欠什么 |
| --- | --- | --- |
| 功能广度 | 编队/任务板/活动流/审批/写操作/胶囊/远程/PWA/扩展卡片 | 成本、产物、回滚、通知后台化、多语言 |
| 稳定性 | 真机验证过、异常态有兜底 | 无自动化测试入库、无 CI、DSH API 单点依赖 |
| 平台 | Windows 胶囊 + 任意平台面板 | macOS/Linux 无胶囊；手机端离线能力弱 |
| 生态 | 卡片 API v1 + 一个示例插件 | 无 SDK 文档站、无第三方模板、无扩展市场 |

## 2. P0 · 必须尽快补的

### P0-1 测试入库 + CI
- **为什么**：现在 6 套 harness（capsule / remote / actions / cards / approval / bridge / state）全在 `tmp/`，发版靠人肉跑，回归成本高且容易漏。
- **怎么做**：把 harness 收进 `tests/`（fake-ctx，不依赖真实 DSH），`npm test` 一键跑；GitHub Actions：`node --check` + `npm test` + 打包校验。
- **验收**：PR 里自动跑测试；本地 `npm test` 全绿；README 有测试徽章。
- **预估**：0.5 天。

### P0-2 DSH API 兼容层
- **为什么**：teammate 遥测依赖 `sessionProjections` + `agents` 服务 + `snapshotEvents`（deprecated）；DSH 一升级就可能整块数据消失。
- **怎么做**：把 projection key、agents 取法、事件钩子收进 `compat.js`；启动时探测能力，缺失则降级（只显示 lead / 隐藏泳道），绝不抛错。
- **验收**：模拟缺失 projection 的 fake-ctx 用例通过；面板不白屏、有降级提示。
- **预估**：1 天。

### P0-3 远程安全补强（按优先级）
- 自动隧道启动目前是「检测 + 给命令」，用户手动复制；文档已写明风险，但应加**默认关闭 + 二次确认**的显式提示（已有确认，补一条"公网可访问"的高危提醒）。
- `cookie Secure` 只在 https 下加（已有）；补 **HSTS 提示**与「用 http 时隐藏 PWA/通知入口」（已隐藏，补文案）。
- 远程 listener 的 `attempts` 已持久化；补**锁定告警**（连续失败达阈值时在桌面设置页提示）。
- **验收**：安全清单逐条有测试或截图证据。
- **预估**：0.5 天。

### P0-4 发布通道
- 仓库已建、v1.0.0 已发布，但**后续更新仍需要 token**（本机 git 到 github.com 不通，走 API 上传）。
- 需要：固定一套「版本 → 打包 → 上传 → Release → 校验」脚本（`scripts/release.mjs`，读 token 环境变量）。
- **验收**：一条命令完成 patch 版本发布；Release 里资产 sha256 与本地一致。
- **预估**：0.5 天 + 每次需要 token。

## 3. P1 · 体验升级（v1.1 候选）

### P1-1 活动流虚拟化 + 降噪
- 现在 host 只保留最近 40 条活动，但 UI 是整段重渲染；长会话滚动会顿。
- 做：窗口化列表（超过 60 条只渲染可视区）、同类工具调用折叠成「运行命令 ×3」、过滤空 detail。
- 验收：1000 条活动注入下滚动 60fps；首屏 ≤ 3 帧。
- **预估**：1 天。

### P1-2 移动端「任务」tab 深化
- 现在手机端任务 tab 只有简单列表；应支持：我的待办、阻塞原因、点进会话、快速发消息。
- 验收：手机单列可完成「看到阻塞 → 发消息催」闭环。
- **预估**：1 天。

### P1-3 设置页诊断
- 一键自检：host 接口是否可用、SSE 是否连上、capsule 是否在跑、远程端口是否监听、当前 DSH 版本、插件版本；一键复制诊断报告。
- 验收：出问题时用户能贴一份报告给维护者。
- **预估**：0.5 天。

### P1-4 键盘与无障碍
- 补：Ctrl/⌘+K 命令面板（跳会话/搜任务/发消息/开关远程）、全局快捷键提示、焦点陷阱统一、tab 顺序审查、减少动效全量覆盖。
- 验收：全流程纯键盘可完成；axe 扫描无 critical。
- **预估**：1 天。

### P1-5 会话切换可分享
- 现在 `?s=` 只在当前标签页生效（SSE 按标签选择）；补「复制当前视图链接」，打开即定位同一会话。
- 验收：两个窗口打开同链接看到同一会话。
- **预估**：0.5 天。

### P1-6 胶囊交互收敛
- 胶囊现在只读；可加：点击胶囊 = 打开 Cockpit（已有「指挥台」按钮，可让整颗胶囊可点）、待审批时点击直接跳到审批卡；**不允许在胶囊里直接审批**（误触风险）。
- 验收：点击命中区有 hover 反馈；误点不产生写操作。
- **预估**：0.5 天。

### P1-7 英文界面
- README 有英文段，UI 仍全中文；i18n 走 `locale` 服务，至少 en/zh 两套，设置页可切换。
- 验收：切英文后无中文残留（截图检查 3 档宽度）。
- **预估**：1.5 天。

## 4. P2 · 能力升级（v1.2 候选）

### P2-1 后台推送（Web Push）
- 现状：审批通知只是页面打开时的 Notification API；页面关了就没提醒。
- 做：HTTPS 前提下接 Service Worker + VAPID，订阅存 host；审批到达时推送到手机；iOS 需 16.4+ 且添加到主屏。
- 依赖：公网 HTTPS（隧道或反代）。
- 验收：手机关页面仍能收到审批推送；点击通知回到对应审批。
- **预估**：2 天。

### P2-2 自动隧道向导
- 从「检测 cloudflared/tailscale + 复制命令」升级为「一键启动隧道、自动获取公网地址、自动填入、显示二维码」。
- 风险：进程托管、退出清理、端口冲突；默认仍需显式开启。
- 验收：一键后手机可访问；关闭时隧道进程随之结束。
- **预估**：2 天。

### P2-3 成本/产物卡片
- 内置「本轮成本、今日 token、余额」与「产物清单（改了哪些文件、测试结果链接）」；以官方卡片形式实现，顺便当扩展 API 范例。
- 验收：卡片可折叠、不拖慢帧率。
- **预估**：1.5 天。

### P2-4 扩展 API v2 + SDK 文档
- 现在卡片是「纯 JSON 展示 + 动作」；v2 增加：自定义渲染 iframe 沙箱、卡片权限声明、`cockpit.state` 订阅、事件回调（部署/测试状态）。
- 验收：外部示例插件以 SDK 发布（npm 不发布，直接 GitHub 模板）。
- **预估**：3 天。

### P2-5 任务板写操作
- 任务改状态/重新指派/解除阻塞（目前任务板只读，只有 todo 计划兜底）。
- 需要：DSH 团队任务 API 的稳定暴露；没有就仅做「点任务跳会话」。
- 验收：改动有审计、失败有回滚提示。
- **预估**：2–3 天（依赖上游）。

### 6.3 每次 DSH 升级后的回归清单
1. `/cockpit/api/state` 200 且 `session/team` 字段齐全
2. 编队成员 token 是否有值（teammate 遥测）
3. 审批：发起一次测试审批，deck 能否允许/拒绝
4. 写操作：发消息、插话、中断各一次
5. 胶囊：运行中、进度帧、关闭开关
6. 远程：开/关、配对、撤销
7. 面板嵌入：侧栏入口、主题跟随、iframe 加载
8. 截图回归 1250 / 1000 / 390

### 6.4 性能预算（当前）
- state 帧 ≤ 30 KB；host 广播合并 260ms；UI 状态签名跳过无变化渲染
- 胶囊：事件 150ms 合并 + 每秒帧；overlay 350ms 读取
- 目标：首屏 < 150ms；常驻内存 < 80MB

- [ ] 配对码单次 + TTL + 失败锁定（已做）

## 7. 已知限制（公开说明时用）

1. Windows 专属胶囊（WPF + PowerShell），其他平台只有面板
2. 手机安装 PWA / 系统通知需要 HTTPS；局域网 http 只能当网页用
3. 后台推送（Web Push）未做，页面关闭后收不到审批提醒
4. 远程访问需要桌面端 DSH 保持运行；没有内置 TLS（需隧道或反代）
5. teammate 遥测依赖 DSH 投影与 agent 服务，上游变更可能降级
6. 任务板以只读展示为主，写操作集中在审批/消息/中断
7. 无自动化测试入库（P0）
8. npm 包名 `dsh-cockpit` 已被占用，npm 发布需换名（GitHub 发布不受影响）
