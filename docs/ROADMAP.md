## 0. 一句话现状

「看 / 批 / 说 / 盯」四件事已经闭环：看板看全局、审批一键过、发消息插话、桌面胶囊和手机远程盯着。
**v1.0 解决「能用」，v1.1 解决「知道哪里坏了」（自检/分享/胶囊点击/空闲写入）；v1.2 该解决「用起来顺」——润色、优化、顺手补洞，不再铺新功能面。**

## 1. 今天的走查结论（v1.2 的依据）

### 1.1 文档/数字失真（已在本版提交修正）

- `CHANGELOG.md` 1.1.0 段曾写「16 tests」，实际 **18**；`ROADMAP` 两处「16 条」同理（已统一）。
- `docs/STATE.md` 抬头曾为 `contract (v0.1)`，但 1.0.1 / 1.1.0 都改过契约（capsule 字段、诊断端点、分享链接）→ 已升 v1.1 并补充只读助手端点说明。
- 本文之前写「v1.1.0 已发布到 GitHub」，与事实不符（见顶部发布状态，已改为「本地未推送」）。

### 1.2 预览/联调缺口

- `scripts/preview.mjs` 没有 `/cockpit/api/diagnostics` 路由 → 在 `npm run preview` 里打开「自检与诊断」必红，无法演示/录屏。
- `mock/state.json` 的 `version` 还是 `1.0.0`，且没有 `capsule` / `capsuleFocus` 字段（与真实 `/api/state` 不一致）。
- 6 套历史 harness 仍在 `tmp/`，未迁入 `tests/`（P0-1 后半）。

### 1.3 CI 守卫缺口（今天的真实坑）

- `capsule/overlay.ps1` 必须是 **UTF-8 带 BOM**，否则 Windows PowerShell 5.1 把中文读成乱码；edit 类工具会静默剥掉 BOM → 需要 CI 守卫。
- CI 现在只查 3 个 JS 的语法：PowerShell 解析、`public/app.css` 括号平衡、`scripts/preview.mjs` 冒烟（起服务抓 200）都没有。
- 本次 WPF 实测结论值得固化：`CaptureMouse` 后子元素收不到 MouseUp，胶囊点击分区只能靠坐标判断（已在 `overlay.ps1` 注释）。

### 1.4 运行期小缺口

- **失效 `?s=` 会弹 toast**：从旧链接进入时 applyState 丢弃选择并提示「该会话已结束」，噪音（应静默回落）。
- **`?focus=approvals` 首帧无审批就被消费**：标记在第一次 state 帧即清空，若那帧审批列表为空，深链静默失效。
- **重载瞬间 running 丢失**：poll 只种子 `lastSeq` 不回放历史，插件 reload / DSH 重启时正在跑的那轮 turn 不可见，直到下一次 turn/start。
- **渲染签名不完整**：`stateSignature()` 覆盖了主体字段，但 `approvals/remote/capsule` 的局部变化仍可能触发整段重渲染。
- **胶囊 hover 反馈弱**：目前只有 tooltip + 读数透明度动画，本体没有视觉高亮。
- **活动流未降噪**：host 只留 40 条，但 UI 整段重渲染，连续工具调用刷屏。

### 1.5 发布通道（最大不确定项）

- 本机到 github.com 不通，1.0.0 之后无法用 git 推送；需要 `scripts/release.mjs` 走 **token + GitHub API** 上传 tgz / 建 Release / 校验 sha256（ROADMAP 旧 P0-4）。

## 5. 验收与回归

每次改动（v1.2 起固定流程）：

1. `npm test`（node:test，18+ 例）全绿
2. `node --check index.js client.js public/app.js` + overlay.ps1 BOM/解析检查（D3 起进 CI）
3. `npm pack --dry-run` 内容与体积无异常
4. `node scripts/preview.mjs` 冒烟：`/cockpit/` 200、设置页自检可点
5. 实机清单（每版一次，重载插件或重启 DSH 后）：
   - `/cockpit/api/state` 200，`session/capsule/team` 字段齐全
   - 审批：允许/拒绝各一次；`?focus=approvals` 深链
   - 写操作：发消息、插话、中断各一次
   - 胶囊：运行中显示、进度帧、点击开指挥台、箭头展开、关闭开关
   - 分享链接：两个窗口同链接同一会话
   - 诊断卡：8 项状态 + 复制报告
   - 远程：开/关、配对、撤销
   - 截图回归 1250 / 1000 / 390 三档宽度

### 性能预算（当前）

- state 帧 ≤ 30 KB；host 广播合并 260 ms；UI 状态签名跳过无变化渲染
- 胶囊：事件 150 ms 合并 + 每秒帧；overlay 读取 ≤ 500 ms；不变帧 30 s/60 s keepalive
- 目标：首屏 < 150 ms；常驻内存 < 80 MB

### 安全清单（已做，保持）

- [x] 远程端口只绑私有网段；配对码单次 + TTL + 失败锁定；Cookie HttpOnly/SameSite/Secure(https)
- [x] 写接口同源校验；审计文件轮转（256 KB → 保留 400 行）
- [ ] 扩展卡片动作信任边界写进文档（本地插件=可信；远程只读）
- [ ] 依赖升级检查（月度）

## 6. 已知限制（对外说明用）

1. Windows 专属胶囊（WPF + PowerShell），其他平台只有面板
2. 手机 PWA / 系统通知需要 HTTPS；局域网 http 只能当网页用
3. 后台推送（Web Push）未做，页面关闭后收不到审批提醒
4. 远程访问需要桌面端 DSH 保持运行；没有内置 TLS（需隧道或反代）
5. teammate 遥测依赖 DSH 投影与 agent 服务，上游变更可能降级（兼容层未做）
6. 任务板以只读展示为主，写操作集中在审批/消息/中断
7. 6 套历史集成 harness 仍在 `tmp/`（单测 18 例 + CI 已入库）
8. npm 包名 `dsh-cockpit` 已被占用，npm 发布需换名（GitHub Release 不受影响）
9. 本机 git 到 github.com 不通，发布依赖 token API 通道（C1 未做前只能本地提交）

## 8. 附录：旧版建议详情（保留备查）

> 以下是从 2026-10-18 版路线图（P0–P3 编号）保留下来的实现细节，新方案以 §2 为准；
> 排期时直接引用这里的「为什么 / 怎么做 / 验收 / 预估」。

### 兼容与稳定

- **DSH API 兼容层（旧 P0-2 → C2）**：teammate 遥测依赖 `sessionProjections` + `agents` 服务 + `snapshotEvents`（deprecated），DSH 一升级就可能整块数据消失。做法：projection key、agents 取法、事件钩子收进 `compat.js`；启动时探测能力，缺失则降级（只显示 lead / 隐藏泳道），绝不抛错。验收：模拟缺失 projection 的 fake-ctx 用例通过；面板不白屏、有降级提示。约 1 天。
- **启动回放（D6）**：插件启动时把最近 ~50 条事件补喂 Tracker，让重载/重启瞬间正在跑的 turn 立即可见；注意用「turn/start 后是否有 turn/end」判定，避免幽灵 running。

### 远程安全（旧 P0-3）

- 自动隧道启动目前是「检测 + 给命令」，用户手动复制；文档已写明风险 → 加**默认关闭 + 二次确认**，并补一条「公网可访问」的高危提醒。
- `cookie Secure` 只在 https 下加（已做）；补 **HSTS 提示**与「用 http 时隐藏 PWA/通知入口」的文案（入口已隐藏）。
- 远程 listener 的 `attempts` 已持久化 → 补**锁定告警**（连续失败达阈值时在桌面设置页提示）。
- 验收：安全清单逐条有测试或截图证据。约 0.5 天。

### 体验与性能

- **活动流虚拟化（旧 P1-1 → B1）**：host 只留 40 条活动，但 UI 整段重渲染，长会话滚动会顿。做：窗口化（超过 60 条只渲染可视区）、同类工具调用折叠成「运行命令 ×3」、过滤空 detail。验收：1000 条活动注入下滚动 60fps、首屏 ≤ 3 帧。约 1 天。
- **移动端任务 tab（旧 P1-2 → C5）**：手机端任务 tab 只有简单列表；补「我的待办、阻塞原因、点进会话、快速发消息」。验收：手机单列能完成「看到阻塞 → 发消息催」闭环。约 1 天。
- **键盘与无障碍（旧 P1-4 → C4 + A2/A5）**：Ctrl/⌘+K 命令面板（跳会话/搜任务/发消息/开关远程）、全局快捷键提示、焦点陷阱统一、tab 顺序审查、减少动效全量覆盖。验收：全流程纯键盘可完成；axe 扫描无 critical。约 1 天。
- **英文界面（旧 P1-7 → C3）**：UI 全中文；i18n 走 `locale` 服务，至少 en/zh 两套，设置页可切换。验收：切英文后无中文残留（截图检查 3 档宽度）。约 1.5 天。

### 能力升级（旧 P2）

- **后台推送 Web Push（P2-1）**：审批通知目前只在页面打开时生效；接 Service Worker + VAPID，订阅存 host，审批到达推送到手机（iOS 需 16.4+ 且添加到主屏）。依赖公网 HTTPS。验收：手机关页面仍能收到审批推送、点击回到对应审批。约 2 天。
- **自动隧道向导（P2-2）**：从「检测 cloudflared/tailscale + 复制命令」升级为「一键启动、自动公网地址、自动填入、显示二维码」；注意进程托管、退出清理、端口冲突；默认显式开启。验收：一键后手机可访问，关闭时隧道进程随之结束。约 2 天。
- **成本/产物卡片（P2-3）**：内置「本轮成本、今日 token、余额」与「产物清单（改了哪些文件、测试结果链接）」；以官方卡片形式实现，顺便当扩展 API 范例。验收：卡片可折叠、不拖慢帧率。约 1.5 天。
- **扩展 API v2 + SDK（P2-4）**：卡片 v2 增加 iframe 沙箱自定义渲染、权限声明、`cockpit.state` 订阅、事件回调（部署/测试状态）。验收：外部示例插件以 SDK 发布（GitHub 模板）。约 3 天。
- **任务板写操作（P2-5）**：改状态/重新指派/解除阻塞（目前只读，只有 todo 计划兜底）。依赖 DSH 团队任务 API 的稳定暴露；没有就只做「点任务跳会话」。验收：改动有审计、失败有回滚提示。约 2–3 天（依赖上游）。
